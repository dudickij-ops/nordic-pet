# s14-site-look — экран читается как часть сайта nordicpet.lt

Канонический текст куска S14. Кусок меняет **оформление, а не содержание**: числа, их
состав, порядок блоков и то, что показано, остаются теми, какими их сдал кусок S13. Единственное
изменение в показанном — написание главного числа шапки (пункт 12), и оно названо отступлением.

Основание вида — **переменные темы сайта**, снятые живым заходом 18.09.2026 и выписанные в
`.contracts/s14-site-look-выписки.md` на этой же ветке: полная выписка семи блоков, у каждого
числа адрес страницы, селектор и дата захода. Чего тема не объявляет — строится нами и помечается
как наш выбор везде, где появляется.

**Договор не правится задним числом.** Отменённое решение не переписывается на месте: заводится
новая запись с датой, причиной и тем, что именно отменено; прежняя остаётся как была.

Кусок S13 (`origin/main`, голова `7d42c11`) собрал отчёт в один экран и сам назвал следующий шаг:
оформление под сайт магазина — отдельный кусок. 18.09.2026 сделан заход на сайт, снята выписка
свойств оформления (`getComputedStyle`, окно 1440 × 900, четыре страницы), и в тот же день владелец
принял по ней четырнадцать решений — таблица ниже. Макет владельца задаёт раскладку, порядок блоков
и ударения, но не числа и не цвета; канонический текст — этот договор.

## Решения владельца, на которых стоит договор

Все приняты **18 сентября 2026 года**. Буква **О** — оформление.

| # | Развилка | Решение |
|---|---|---|
| О1 | Что делает кусок | Экран читается как часть сайта nordicpet.lt. Содержание и числа не меняются |
| О2 | Канон вида | **Переменные темы сайта**, а не то, что показывают страницы. Пять семейств и тринадцать кеглей — шум, и договор обязан это назвать. Чего тема не объявляет — строим сами и помечаем как наш выбор |
| О3 | Сколько переносить | **Подход Б**: типографика (семейства, шкала кеглей, насыщенности, межстрочное), смысловые цвета, скругления, тёмная карточка результата, ширина колонки. Отступы, тени и рамки остаются нынешние — назвать отступлением заранее |
| О4 | Полоса пунктов наверху | **Шапка сайта, а не вкладки**: ссылки-якоря на блоки того же экрана. Решение Э2 куска S13 (один экран) в силе |
| О5 | Округление | Целыми евро — **только главное число шапки**; точная сумма с центами мелкой строкой под ним. Прочие суммы с центами, каскад сходится до цента. **Округляет запрос, не экран** |
| О6 | Цвета | Зелёный — вердикт «лучше», итоговые ступени каскада, знак и имя магазина. Красный — отказы и плохие значения, включая убыток. Коричневый — **только** столбики снятых сумм каскада. Жёлтого нет нигде; плашка точности из макета не берётся |
| О7 | Какой зелёный | Фирменный — `rgb(126, 191, 154)` из переменной темы, **не** зелёный логотипа. Для зелёного текста и тонких линий — затемнённый вариант, посчитанный до порога контраста и показанный числом |
| О8 | Тёмная карточка результата | Фон `rgb(0, 0, 0)`, белый текст — как у шапки сайта и первого экрана главной |
| О9 | Товары | Раскрытие остаётся на месте, без ухода со страницы; переключатель переезжает в заголовок блока и выглядит кнопкой |
| О10 | Качество данных | Три колонки «откуда числа»: из сверки месяца / наш счёт / чего нет в источниках. Новых чисел не появляется — только перегруппировка показанного |
| О11 | Раскладка | Тёмная карточка результата с прибылью и тремя спутниками справа (чистая выручка, маржа, окупаемость с плашкой порога); выводы — карточками с цветной полосой слева, заголовок жирным, пояснение под ним; каскад — подписи слева, полосы по центру, суммы и доли справа, легенда и оговорка снизу; ряд по дням с пунктиром средней; товары — артикул, сумма, полоса, доля справа |
| О12 | Пустые состояния | «Сравнить не с чем» — пунктирная рамка с объяснением, пустой ряд — штриховка. Ноль вместо «данных нет» запрещён |
| О13 | Чего в куске нет | Анимаций, новых блоков, печати, изменения чисел, порядка блоков и состава показанного |
| О14 | Тёмная тема | **Держится наравне со светлой.** Каждая новая величина получает тёмное значение; у сайта тёмной темы нет, переносить нечего, поэтому оно помечается как наш выбор. Меряется на контраст наравне со светлым, решение по каждой паре — **по худшей стороне**. Снимки сдаются парами «до / после» в обеих темах |

## Что кусок обязан сделать

### Величины вида

| # | Требование |
|---|---|
| 1 | **Источник у каждой величины.** В `app/globals.css` не остаётся величины без источника. Источников три: выписка сайта (значение и адрес стоят у величины); выписка Fluent 2, уже живущая в принятой проверке `__tests__/styles/fluent-tokens.test.ts` (для отступов, теней и рамок — решение О3); **закрытый список названных наших величин** — имя, значение, довод, пометка «наш выбор». Проверка величин переписывается под этот состав, остаётся закрывающей по умолчанию и смотрит оба блока — светлый и тёмный |
| 2 | **Шкала кеглей — наша, собранная из замеров.** Тема шкалы не объявляет: ступени берутся из замеров выписки, у каждой стоит адрес. Ступень, которой в выписке нет, заводится в списке наших величин с доводом, а не подбирается к соседней. То же для межстрочных и насыщенностей |
| 3 | **Семейства — только из темы:** `"Barlow", Arial, Helvetica, sans-serif` для текста и заголовков. Четыре остальных семейства страниц не переносятся. Шрифтовые файлы наружу не тянутся: запасные семейства обязаны отработать, и чем это закрыто — называется в теле заявки |
| 4 | **Фирменный зелёный** — ровно `rgb(126, 191, 154)`. Зелёный логотипа (`rgb(85, 184, 137)`, замер выписки по картинке) не берётся |
| 5 | **Затемнённый зелёный.** Порядок — **наш**, решением не задан: сперва проверяется `rgb(32, 64, 61)` из выписки; проходит порог на худшей паре — берётся как величина выписки с адресом; не проходит — считается наш вариант с пометкой «наш счёт по формуле контраста, а не выписка» и числом рядом. Третьего — правдоподобное значение без числа — нет |
| 6 | **Смысловые цвета** по О6. Жёлтого нет ни в одном правиле: ни `#fbbc34`, ни `rgb(255, 187, 54)`. **Красного и коричневого в выписке сайта нет вовсе:** красный остаётся из выписки Fluent (уже принят и замерен), коричневый — наша величина с именем, доводом и числом контраста |
| 7 | **Тёмная карточка результата** — фон `rgb(0, 0, 0)`, текст белый; адреса замера — полоса шапки и первый экран главной |
| 8 | **Скругления.** В выписке два значения, `20px` и `0px`; про карточку дашборда тема молчит — выбор записывается в список наших величин с доводом |
| 9 | **Ширина колонки** — `max-width: 1222px` и поля `15px`. Число `1192px` в таблицу стилей не попадает: ширину под содержимое считает браузер |
| 10 | **Контраст.** Таблица `docs/сверка/контраст.md` пересобирается целиком **по списку соседств**, как в куске S10: пары соседних цветов у каждого элемента, а не пары, о которых думает автор. У каждой пары стоят кегль и насыщенность — без них неизвестно, какой порог применять (**наш вывод**). Решение — по худшей паре. Приглушать прозрачностью запрещено: ни `opacity`, ни альфы ниже `1` у текста и смысловых цветов. Порог — выписка прежнего куска, приведённая целиком и с условием (`docs/сверка/контраст.md`, цитата справочника Fluent, `fluent2.microsoft.design/typography`, «Styling text» → «Color»): «Standard text must have a contrast ratio of at least 4.5:1 against its background. Large text (above 18.5 pixels bold, or 24 pixels regular) must have a contrast ratio of at least 3:1.» |
| 11 | **Тёмная тема — наравне со светлой (О14).** Каждая величина, заведённая или изменённая куском, получает значение и в блоке `@media (prefers-color-scheme: dark)`; тёмные значения помечены как наш выбор — на сайте их взять неоткуда. Каждая пара соседств меряется в обеих темах, и решение по паре принимается по худшей из двух сторон |

## Утверждения, которые обязаны ломаться

Каждое ломается машинально; у каждого свой слом в `breaks/s14-site-look.ts`.

1. **Величины без источника нет:** величина вне выписки сайта, выписки Fluent и списка наших не встречается ни в светлом блоке, ни в тёмном, ни в правилах.
2. **У каждой заведённой куском величины есть тёмное значение:** имена светлого и тёмного блоков сверяются по составу, разница — отказ.
3. **Главное число — целыми евро, точная сумма рядом:** в шапке стоят обе строки, и в разметке нет ни `toFixed`, ни `Math.round`, ни иного округления.
4. **Округление не разлилось:** ни одна сумма каскада не напечатана целыми, и каскад сходится до цента.
5. **Коричневый — только столбики снятых сумм:** его величина встречается ровно в этих правилах и ни в одном правиле выводов, знаков и вердиктов.
6. **Жёлтого нет:** ни `#fbbc34`, ни `rgb(255, 187, 54)` не встречаются ни в правиле, ни в объявлении величины.
7. **Пункты шапки — якоря того же документа:** у каждого `href` начинается с `#`, на экране есть элемент с таким `id`, внешних адресов нет.
8. **Фирменный зелёный — ровно `rgb(126, 191, 154)`:** другого зелёного в правилах нет, `rgb(85, 184, 137)` не встречается.
9. **Роли цветов не перепутаны:** зелёного нет в правилах отказов, красного — в правиле вердикта «лучше», убыток красный.
10. **Контраст покрыт целиком:** число строк таблицы замеров равно числу пар списка соседств, у каждой паре стоят кегль и насыщенность, и худшая пара проходит свой порог.
11. **Тёмная тема мерена наравне:** у каждой пары в таблице есть оба замера — светлый и тёмный, — и порог проверяется по худшей стороне.
12. **Ничего не приглушено прозрачностью:** в правилах текста и смысловых цветов нет `opacity` и нет цвета с альфой ниже `1`.
13. **Тёмная карточка результата чёрная с белым текстом:** фон `rgb(0, 0, 0)`, текст `rgb(255, 255, 255)`.
14. **Крупное число на экране одно** — прибыль: утверждение S13 остаётся верным на новой шкале кеглей.
15. **Пустые состояния честны:** у блока без базы есть пунктирная рамка и текст объяснения, у пустого дня — штриховка, и ни в одном из этих мест не напечатан ноль.
16. **Состав и порядок блоков не изменились:** те же `id` в том же порядке, что на голове S13.
17. **Числа не изменились:** перепись экрана совпадает с прежней везде, кроме главного числа шапки и строки точной суммы под ним.
18. **Переключатель товаров** — кнопка внутри заголовка блока; раскрытие работает без клиентского кода и не уводит со страницы.
19. **Блок качества не принёс новых чисел:** множество показанных значений совпадает с прежним.

| Место | Что | Довод |

| Отступы, тени, рамки | остаются из выписки Fluent, а не с сайта | решение О3; перенести их вместе со шкалой отступов — второй кусок работы. Названо отступлением, а не починено |
| Главное число целыми евро | правило «кусок не меняет числа» нарушено ровно здесь | решение О5; закрыто точной суммой рядом и тем, что округляет запрос. Утверждения 3 и 4 сторожат обе половины |

| Тёмные значения величин | целиком наш выбор | О14: у сайта тёмной темы нет, переносить нечего; помечены как наши и замерены наравне со светлыми |
| Четыре семейства шрифтов со страниц | не переносятся | О2: канон — тема, а она объявляет только `Barlow` |

## Пути, которых нет в настоящих данных

В данных один месяц — март. На нём реклама окупается, месяц в плюсе, прошлого месяца с заказами
нет. Всё, что ниже, увидено только на выдуманных раскладках — на приёмке смотреть туда первым делом.

| Состояние экрана | Где проверено |
|---|---|
| Убыток: главное число красным | только выдуманные итоги |
| Плашка порога в состояниях «не окупается», «порога нет», «рекламы нет» | только выдуманные итоги |
| Карточка вывода с красной полосой | только выдуманные итоги |
| Дельты у трёх чисел, то есть вид **без** пунктирной рамки | только выдуманная раскладка: у марта базы нет, и настоящий вид марта — как раз пунктирная рамка |
| Пять артикулов и меньше: переключателя нет | только выдуманная раскладка |
| Блок качества без единой дыры | только выдуманная раскладка |
| Длинное имя месяца и узкий экран в новой типографике | только выдуманная раскладка |

**Штриховка пустого дня — путь настоящих данных, а не выдуманный.** В марте **1** день без
заказов: `docs/сверка/числа-марта-s13.md` на `origin/main`, строка 3 — «Дней без заказов в марте:
1», записана по живому заходу куска S13. Проверено командой `git grep -n 'Дней без заказов'
origin/main -- 'docs/сверка/числа-марта-s13.md'`. Значит штриховка обязана быть видна на снимке
марта, а не только на выдуманной раскладке.
