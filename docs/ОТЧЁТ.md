# Финальный отчёт — дашборд прибыли Nordic Pet

Дашборд работает на `nordic-pet.vercel.app`, закрыт входом по паролю, показывает прибыль
магазина за выбранный месяц. Работа разрезана на одиннадцать кусков; каждый прошёл контракт, план,
код и проверку кода тем, у кого не было контекста автора.

Отчёт написан по трём вопросам приёмки: **что сделал, чего не сделал, где не уверен.** Ниже них —
полный список отложенных задач и указание, где лежит след работы.

Слом — это утверждение о механизме, записанное так, чтобы его можно было запустить: ломаем
механизм, смотрим, покраснела ли **его собственная** проверка, возвращаем файл. Красное вообще
ничего не доказывает; доказывает только красное у той проверки, которая сторожит именно это
утверждение.

## Чего не сделал

| Что | Почему |
|---|---|
| Знак магазина на экране | решение владельца: нынешнего вида достаточно |
| Сортировка таблицы нажатием, свёртки блоков, графики | это поведение, а не вид; любое требует счёта на экране или новых полей отчёта |
| Роль базы с правом только на вызов функций записи | смена модели безопасности базы и миграция в бой — отдельный кусок работы |
| Живая проверка на настоящем общем диске | общего диска у нас нет; поведение Google на нём никем не наблюдалось |
| Сломы **на вид** экрана | и это надо отличать от чисел таблицы стилей, которые сторожатся. **Числа сторожатся:** проверка читает `app/globals.css` и сверяет каждую величину с выписанной из Fluent 2, а пять сломов доказывают, что подмена величины, размер вне шкалы, посторонний цвет, третий блок величин и возврат прежнего селектора отключённого вида — каждое красит свою проверку. **Вид не сторожится ничем, кроме снимка и глаза:** правильные числа, собранные в уродливый экран, пройдут проверку зелёными. Это две разные вещи, и здесь названы обе |
| Несколько магазинов, несколько валют, права пользователей | в задании этого нет |
| Показ строк-близнецов на экране | они видны в выводе команды разбора; вынести их на экран — это «что», а не «как» |

## Где не уверен

| Место | В чём неуверенность |
|---|---|
| **Развилка правил 4 и 5** | буква правила 5 снимает себестоимость возвращённых штук, буква правила 4 определяет себестоимость товара без цены как 40 % чистой выручки, из которой возвраты уже вычтены. Исполнить обе дословно значит снять возвраты дважды. Наше прочтение даёт себестоимость 6 028,11 € против 5 894,31 € — **2,22 % при пороге приёмки 0,5 %**, по прибыли разрыв 7,70 %. Направление важно: у нас себестоимость **больше**, прибыль **меньше** |
| **Заказ без ставки комиссии** | даёт ноль комиссии молча — единственное место, где ноль встал вместо «нет данных» без называния. Путь закрыт двумя отказами разбора и на мартовские числа не влияет |
| **Поведение Google на общем диске** | доказано составом наших запросов и цитатами справочника, а не живой папкой |
| **Доля честности вне 0…100** | арифметически возможна, в настоящих данных не встречалась ни разу |
| **Вид в других движках** | проверен в одном; Safari и Firefox не смотрел |
| **Месяцы, кроме марта** | живьём считался только март; остальные месяцы проходили через код, но их числа никто не сверял |
| **Переменные `SUPABASE_*` при пересоздании базы** | снимаются только `PG*`; влияют ли `SUPABASE_*` на то, какие миграции применятся, не проверял никто |

## Отложенные задачи — полный список

Собран из тел pull request всех кусков. Сегодня таких заявок **десять** — № 2–7 и № 9–12;
заявка куска S10 станет одиннадцатой. Остальные три из тринадцати слитых отложенных задач не
несут: № 1 и № 8 служебные, № 13 — сам этот отчёт. У каждой строки ниже — причина, по которой она
не сделана, и чем она грозит на деле. Доказательства по каждой лежат в её pull request.

### Права и защита базы

| Задача | Причина | Чем грозит |
|---|---|---|

| Задача | Причина | Чем грозит |

### Вид экрана

| Задача | Причина | Чем грозит |
|---|---|---|
| Защиты, живущие в таблице стилей, без сломов | их две: приведение длины полосы к пределам и гашение устаревших чисел. Сломать их проверкой нельзя — нужен прогон в настоящем браузере | удаление одной строки вернёт ложь «полоса во всю дорожку при отрицательной доле», и ни один слом не увидит |
| Липкая шапка таблицы не работает уже 768 пикселей | уже с этой ширины **карточка «Товары»** становится своим контейнером горизонтальной прокрутки, а внутри контейнера прокрутки прилипание считается от него, а не от страницы. Наш замер: прокрутка на 900 пикселей, при 1280 верх шапки идёт с 544 к 0, при 390 — с 773 к −127 | на узком экране числа читаются без подписей колонок |
| Сторож снимков заморожен, и он не ловит перепутанные темы | сторожа сравнивают светлую и тёмную стороны между собой, и ни одна из сторон не привязана к источнику. Заморожен после трёх кругов проверки кода: прибор съел бюджет куска | перестановка двух веток в сборке развела бы темы по неверным сторонам, и весь набор проверок остался бы зелёным. Ловит это только глаз на снимках |
| Сломы разметки трёх прежних списков гоняют один файл проверок, а не весь набор | так они заведены: `s5-metrics`, `s6-access`, `s8-holes` — девятнадцать сломов, у каждого в наборе стоит один файл | их зелень читается сильнее, чем есть: «проверено механизмов: 87» понимается как «поймано всем, что у нас есть», хотя поймано одним файлом из шестидесяти одного. Закрывается переводом на полный набор и дописыванием объявления красного — тем же приёмом, каким это сделано для `s9-screen` |
| Полоса управления распадается в двух состояниях из пяти | цена расположения кнопок в разметке: кнопка выхода, кнопка обновления и название лежат в разных ветвях и на разной глубине, и собрать их в один ряд удаётся плавающими блоками только пока между ними ничего не стоит. Единственный оставшийся путь стилями — цепочка `subgrid` через шесть уровней вложенности | на холодном открытии «Выйти» на 74 пикселя выше остальной полосы; при отказе шага название на 148 пикселей ниже кнопок |
| Во время обновления человеку не сказано словом, что оно идёт | кнопка на время работы становится отключённой, и это единственный признак; текста «обновляем» на экране нет | человек, не заметивший смены вида кнопки, нажмёт второй раз и получит отказ «занято» вместо понятного ожидания |
| Типографика и правило фокуса сломов не имеют | обе живут только в таблице стилей: сломать их проверкой нельзя, нужен прогон в настоящем браузере | снятая обводка фокуса или сбитая ступень шкалы не покраснят ни одной проверки; ловит это только глаз на снимке |
| Снимки делаются раскладкой, а не живым экраном | снимок с живого экрана потребовал бы входа и пароля | снимок и бой могут разойтись, и заметит это только глаз |

сломов — что из этого проверено красным, а что осталось словами.

## Как запустить и посмотреть

| Что | Как |
|---|---|
| Адрес дашборда | `https://nordic-pet.vercel.app` |
| Вход | по логину и паролю; они передаются отдельно от этого отчёта и в репозитории не лежат |
| Что видно без входа | ничего: ни экрана, ни чисел, ни адресов, по которым страница берёт числа |
| Обновление данных | кнопка «Обновить данные» на самом экране: перечитывает оба источника и пересобирает факты |
| Месяц | берётся из адреса (`?m=2026-03`); без него показан последний месяц, за который есть заказы |

**Дашборд только читает Google и никогда туда не пишет.** У служебного аккаунта доступ
«Просмотр», и у Google запрашиваются области **только на чтение** — отдельная для Таблицы,
отдельная для Диска.

**Замок от подбора пароля запирает и нас.** Десять неверных попыток подряд закроют дашборд на
пятнадцать минут для того, кто ошибался. Это исправная работа механизма, а не поломка.

Запустить у себя: нужны PostgreSQL 15 и Supabase CLI, дальше — `npm run db:reset`, `npm test`,
`npm run dev`. Полностью это описано в README.
