# Снимки экрана — кусок S9

Вид экрана сломами не сторожится: проверка, читающая ввоз таблицы стилей в исходном тексте,
доказывала бы наличие строки, а не наличие вида. Поэтому доказательство здесь — снимок и глаз,
и лежит оно в репозитории, а не в пересказе.

| Файл | Что на нём |
|---|---|
| `01-obychnyy-shirokiy-svetlaya.png` | обычный экран за март, широкий монитор, светлая тема |
| `02-obychnyy-shirokiy-tyomnaya.png` | он же, тёмная тема |
| `03-obychnyy-uzkiy.png` | он же на узком экране: подписи слева, числа справа, таблица товаров прокручивается сама |
| `04-chisla-otstali.png` | пометка «числа отстали от источников» при холодном открытии |
| `05-otkaz-shaga.png` | отказ шага обновления: текст отказа и погашенные числа с пометкой «устарели» |
| `06-otkaz-bazy.png` | «данные не читаются»: наш текст, кнопка выхода, ни адреса базы, ни имени пользователя |
| `07-vhod.png` | страница входа с отказом «логин или пароль не подошли» |

Рядом лежат те же состояния страницами (`*.html`, светлые и `-dark`): их можно открыть в
браузере и потянуть за край окна, чтобы увидеть поведение на любой ширине.

## Чем эти снимки не являются

Числа на них — настоящие мартовские, но взяты раскладкой, а не живым запросом к базе: снимок
делается без входа и без соединения. Что живой экран показывает те же числа, доказывается не
здесь, а выводом команды метрик и проходом целиком по боевому адресу.

## Ловушка, на которой это уже споткнулось

Машина, на которой снимки делаются, стоит в тёмной теме, и безголовый браузер честно отвечает
«prefers-color-scheme: dark». Первый заход дал два **побайтно одинаковых** файла: «светлый»
снимок вышел тёмным. Глазом это не ловится — оба выглядят правдоподобно; поймано сравнением
хешей. Поэтому обе темы в снимках задаются явно, а не полагаются на настройку машины.
