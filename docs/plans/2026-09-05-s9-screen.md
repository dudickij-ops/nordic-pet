# S9 — вид экрана

> **Исполнителю:** план исполняется задача за задачей; между задачами — проверка кода тем, у
> кого нет контекста автора. Шаги помечены `- [ ]` для отметки.

**Цель:** сделать экран настолько хорошим, насколько получится, не сдвинув ни одного числа и не
потеряв ни одной подписи, пометки и отказа.

**Устройство:** одна таблица стилей на всё приложение, подключённая в корневой разметке.
Разметка двигается только там, где стилями не выходит; каждый сдвинутый якорь слома прежнего
куска переводится вместе с кодом. Числа на экран приходят готовыми строками из слоя метрик —
слой метрик кусок не открывает вовсе.

**Чем пользуемся:** Next.js 16 (глобальная таблица стилей подключается ввозом в корневой
разметке), обычный CSS без сборочных надстроек и без внешних шрифтов, vitest 4.

**Контракт:** `.contracts/s9-screen.md` на ветке `contract/s9-screen`, принят владельцем
5 сентября 2026 года: развилки 1, 3, 4, 5, 6 — как рекомендовано, развилка 2 решена владельцем
против рекомендации (полосу делать), плюс три добавления в приёмку.

## Решение владельца по полосе — записано его словами

Я рекомендовал полосу не делать, сославшись на правило «экран не считает». Владелец отклонил
рекомендацию и поправил прочтение правила: **правило запрещает вычислять, а не показывать.**
Ширина берётся из того самого числа, которое рядом напечатано текстом; ни деления, ни вычитания,
ни приведения в разметке не происходит.

**Условие, выставленное вместе с разрешением:** и текст, и ширина берут одно и то же значение из
одного места, и это утверждает проверка. Полоса — единственный графический элемент куска.

- [ ] **Шаг 2. Съём чисел из разметки по порядку.** Теги заменяются переносом строки, чтобы
      соседние значения не слиплись в одно; из полученного текста вынимаются все числа, каждое
      со своим знаком, если он есть.

```tsx
/**
 * Все числа страницы в порядке появления. Знак валюты, процента и окупаемости — часть числа.
 *
 * Разделитель разрядов написан последовательностью `\u00A0`, а не сам собой: `groupDigits`
 * ставит там неразрывный пробел, перед знаком евро стоит обычный, и в исходном тексте они
 * неразличимы на глаз. Правка вслепую сломала бы съём молча.
 */
function числаПоПорядку(html: string): string[] {
  const текст = html.replace(/<[^>]*>/g, '\n')
  return текст.match(/−?\d[\d\u00A0]*(?:,\d+)?(?: [€%×])?/g) ?? []
}
```

- [ ] **Шаг 3. Перепись целиком.** Список выписывается **по наблюдению сегодняшней разметки**, а
      не по догадке: сначала прогон печатает то, что вышло, и наблюдённое переносится в список.
      Если наблюдение разошлось с написанным ниже — правится список, и правится **до** первого
      тронутого тега.

```tsx
test('перепись: все числа экрана, в порядке появления и без единого лишнего', () => {

    '2026', '03',                                    // ссылка месяца

    '5\u00A0555,55 €', '6\u00A0666,66 €', '7\u00A0777,77 €', '8\u00A0888,88 €',
    '9\u00A0999,99 €', '12,3 %', '45,6 ×',
    '101', '71', '1\u00A0010,10 €', '2\u00A0020,20 €', '3\u00A0030,30 €',
```

## Задача 13 — проход целиком в бою

Проверки частей этого не заменяют. У закрытого паролем пути проход состоит из двух заходов.

- [ ] Выкладка ветки на предпросмотр хостинга.
- [ ] Заход снаружи, без ключа: ни экрана, ни чисел не видно.
- [ ] Заход с ключом — **пароль набирает владелец**: логины и пароли придумывает, кладёт и

- [ ] Пять итогов на экране сверяются глазами с выводом команды метрик.
- [ ] «Обновить данные» нажимается дважды подряд: ни одно число не меняется.
- [ ] Выход работает.
- [ ] **Заход владельца глазами по боевому адресу — обязательный шаг приёмки, а не пожелание**
      (добавление владельца № 3). Без него кусок не сдан.
- [ ] **Предупреждение владельцу перед проходом:** замок на подбор запирает и нас — десять

## Список сломов — семь своих плюс одиннадцать переводов

**Задача 2, сеть безопасности**

| Что ломаем | Что обязано покраснеть |
|---|---|
| переставить местами два денежных значения в разметке | перепись: все числа экрана, в порядке появления |
| перевернуть порядок товаров в разметке | перепись: все числа экрана, в порядке появления |
| печатать только ненулевые строки неполноты | на экране все одиннадцать видов неполноты |

Первый слом стоит отдельного слова: **принятые проверки экрана от него не краснеют** — оба
значения на странице остаются, а `toContain` слеп к порядку. Красным становится только перепись,
и это ровно то, ради чего она заведена.

**Задача 7, полоса доли честности**

| Что ломаем | Что обязано покраснеть |
|---|---|
| задать полосе постоянную ширину | доля: и текст, и ширина полосы берут одно значение |
| взять ширину из маржи вместо доли | доля: и текст, и ширина полосы берут одно значение |
| рисовать полосу, когда доли нет | нет доли — нет полосы |

**Задача 8, гашение устаревших чисел**

| Что ломаем | Что обязано покраснеть |
|---|---|
| убрать атрибут состояния с обёртки чисел | отказ со щелью: и текст, и изменённый вид чисел |

**Задача 9, переводы** — одиннадцать якорей прежних кусков; утверждение и ожидание у каждого
прежние, доказательство — прогон своего списка.

Слома на «таблица стилей не подключена» не заводится, и это решение, а не забывчивость:
проверка, читающая ввоз в исходном тексте, доказывала бы наличие строки, а не наличие вида.
Слабую проверку лучше назвать отсутствующей, чем выдать за гарантию.

## Как доказывается главное

| Утверждение | Наблюдение, а не пересказ |
|---|---|
| Числа не поехали в источнике | пустой `git diff` по запретному списку, с кодом возврата |
| Числа не поехали на экране | перепись краснеет от перестановки двух значений — показано сломом |
| Числа не поехали в бою | вывод команды метрик до и после, построчно, `diff` пуст |
| Загрузка не поехала | 4 файла, 1699 / 2908 / 2814 / 986 байт, 279 строк, 186 после свёртки |
| Полоса не врёт | текст и ширина взяты из одного значения; постоянная ширина краснит проверку |
| Ничего не потеряно | принятые проверки прежних кусков зелены без правки утверждений |
| Вид вправду хорош | глаз владельца по боевому адресу — обязательный шаг, а не пожелание |

## Куда смотреть первым делом

1. **Перепись на сегодняшней разметке.** Если она не зазеленела с первого раза — сначала
   выяснить, разошёлся ли список с наблюдением, и только потом трогать теги. Правка списка
   после первого тронутого тега уже ничего не доказывает.
2. **Отступы в разметке страницы отчёта.** Якоря сломов цитируют её с точностью до пробела.
   Обёртка вокруг блока сдвигает отступы детей — и рвёт якорь, о котором не думали.
3. **Атрибут `data-stale`.** Он выглядит как след отладки и просится на удаление при
   переезде на классы. На нём держатся принятые проверки прошлого куска.

## Пути, ни разу не виденные в настоящих данных

- Доля честности, равная нулю или ста процентам: полоса нулевой и полной длины в бою не
  показывалась ни разу.
- Отрицательная прибыль на экране: за март она положительная, и вид минуса проверен только
  на выдуманной раскладке.
- Экран на месяце, где заказов нет вовсе: пустая таблица товаров в бою не открывалась.
- Отказ базы при открытой странице отчёта.

## Известные ловушки, которые выстрелят потом

- **Отложенная задача про неразрывный пробел перед знаком евро закрывается стилями, а не
  форматом.** Тот, кто однажды откроет формат и поправит литерал, покрасит принятые проверки
  формата и получит две правки одного и того же в двух местах.
- **Перепись чисел придётся править всякий раз, когда на экран сознательно добавляется новое
  число.** Это не дефект, а цена: правка переписи обязана быть видна в диффе и названа.
- **Строки-близнецы по-прежнему не видны на экране.** Унаследовано от S4, в этот кусок не
  входит: это «что», а не «как».
