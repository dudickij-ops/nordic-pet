Команда:

```bash
node --input-type=module -e "import pg from 'pg'; import { projectDatabaseUrl } from './lib/db-url.ts'; const p = new pg.Pool({ connectionString: projectDatabaseUrl() }); const r = await p.query(\"select count(*)::int as n from generate_series('2026-03-01'::date, '2026-03-31'::date, interval '1 day') d where d::date not in (select min(o.date) from fact.orders o group by o.order_id)\"); console.log('days_without_orders', r.rows[0].n); await p.end()"
```

запасного `.mjs`-скрипта.

## Задача 17: сверка загрузки с независимым счётом владельца (утверждение 7)

Правка по итоговой проверке (находка И8): строка приёмки «загрузка сверена с независимым счётом
владельца по листам и с 279 строками рекламы» была доказана только в отчёте задачи 0, а в ветке — нет.
Нового захода эта таблица не делала: наш счёт переписан из отчёта задачи 0
(`.superpowers/sdd/2026-09-16-s13-one-screen/task-0-report.md`, шаг 1) вместе с командами, которые его дали.

**Когда снято.** Отчёт задачи 0 дату и голову захода не называет. Заход вошёл в коммит задачи 0 `ba9dd1d`
от 2026-09-16 20:32:33 +0300, родитель `a9d1245` (`git log -1 --format='%h %ad parent=%p' --date=iso ba9dd1d`) —
это наш вывод из истории, а не запись самого захода.

**Счёт владельца** — числа, которые владелец передал как полученные мимо нашего кода; в ветке они стоят в
