# Рецепты Fluent, взятые экраном, — сверка по каждому свойству

Кусок S10, круг правок 2. Решение владельца от 10 сентября 2026 года, его словами: «Берём у Fluent
компонент — выписываем **весь** его стилевой блок с диапазоном строк и сверяем наше правило по
каждому свойству: совпало или названо отступлением. Не «нужную строку»».

**Полнота выписки — вывод команды.** Одноразовый разбор (в репозиторий не кладётся) прошёл по
выписанным блокам источника — их диапазоны строк стоят в начале каждого раздела — и для каждой
строки вида `имя: значение` искал её номер среди номеров в строках таблицы своего раздела. Вывод
на коммите источника `43665d5`, 10 сентября 2026 года:

```
раздел 1: строк-свойств 93, не упомянуто 0
раздел 2: строк-свойств 10, не упомянуто 0
раздел 3: строк-свойств 36, не упомянуто 0
раздел 4: строк-свойств 30, не упомянуто 0
раздел 5: строк-свойств 53, не упомянуто 0
раздел 6: строк-свойств 44, не упомянуто 0
раздел 7: строк-свойств 25, не упомянуто 0
ВСЕГО НЕ УПОМЯНУТО: 0
exit=0
```

**Чего этот вывод не доказывает.** Разбор не исполняет TypeScript; открывающие строки блоков
(`root: {`, `'::before': {`) свойствами не считает; номера засчитывает только из строк таблиц, не из
заголовков и абзацев; утверждает, что номер строки упомянут, а не что итог у строки верен. Что
выбраны нужные блоки и что итоги верны — доказано якорями и человеком, а не механизмом.

**Источник:** `microsoft/fluentui`, коммит `43665d5fb41408837ad1e85eb662575da9e0c4d0`. Все пути ниже —
от `packages/react-components/`. Выписка — таблица свойств, а не копия кода; номер строки у каждого
свойства ведёт в файл источника.

**Какие компоненты — установлено командой, а не по памяти.** Поиск имён файлов `use*Styles.styles.ts`
в `app/globals.css`, 10 сентября 2026 года, дал семь файлов: кнопку, поле ввода, полосу прогресса,
разделитель, ячейку таблицы, шапку ячейки и строку таблицы. Разделы ниже — по одному на файл.

```
$ grep -o 'use[A-Z][a-zA-Z]*Styles\.styles\.ts' app/globals.css | sort | uniq -c
   4 useButtonStyles.styles.ts
   1 useDividerStyles.styles.ts
   1 useInputStyles.styles.ts
   1 useProgressBarStyles.styles.ts
   1 useTableCellStyles.styles.ts
   1 useTableHeaderCellStyles.styles.ts
   1 useTableRowStyles.styles.ts
```

**Режим высокой контрастности не взят:** блоки `@media (forced-colors: active)` источника. Своего
оформления для этого режима экран не заводит — в нём браузер подставляет системные цвета сам. В
таблицах такие блоки стоят строкой «не взято, общее для всех», довод — этот абзац.

Итоги в таблицах: **совпало**; **совпало по действию** — наше правило даёт тот же вид иным путём;
**не взято** — свойство не перенесено; **отступление** — перенесено иначе; **не применимо** — у нас
нет той части компонента, к которой свойство относится. При «не взято» и «отступлении» пишется
довод словами либо «довода в коде нет».
