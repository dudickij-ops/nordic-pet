# Сверка чисел на куске S10

Кусок S10 меняет только оформление экрана. Числа он не открывает вовсе — но «не открывает»
обязано быть наблюдением, а не обещанием.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `метрики-2026-03-до.txt` | вывод команды метрик за март **до** первой правки оформления, снятый на живых данных |
| `контраст.md` | контраст экрана по списку соседств — 45 пар, обе темы и погашенный вид; наш замер с отрисованных страниц, а не выписка |
| `рецепты-fluent.md` | сверка семи взятых у Fluent компонентов по свойствам их стилевых блоков, с выводом проверки полноты |

## Чем эта сверка является — и чем не является

Она состоит из трёх разных действий, и называть их одним словом «числа проверены» нельзя.

**Первое: два живых захода.** Файл «до» снят живой загрузкой Таблицы и папки Диска в местную
базу. В конце куска живой заход повторяется, и вывод команды метрик снимается второй раз.

**Второе: побайтное сравнение** двух этих выводов. Оно показывает, что между двумя заходами не
сдвинулось ничего.

**Третье: сличение с независимым счётом владельца — один раз, глазами, по пяти строкам.**
Побайтное сравнение само по себе доказывает меньше, чем кажется: если оба захода одинаково
неверны, оно остаётся зелёным. Поэтому файл «до», прежде чем стать эталоном куска, был сверен
с числами, которые владелец посчитал сам и отдельно от нашего кода:

| Строка | Счёт владельца | Файл «до» |
|---|---|---|
| оборот | 18 764,00 € | 18 764,00 € |
| чистая выручка | 17 277,04 € | 17 277,04 € |
| прибыль | 1 738,53 € | 1 738,53 € |
| маржа | 10,1 % | 10,1 % |
| окупаемость рекламы (по обороту) | 4,23 × | 4,23 × |

Сошлись все пять. Дальше по куску работает побайтное сравнение; сличение с независимым счётом
больше не повторяется, и потому оно названо здесь — один раз, по пяти строкам, на файле «до».

## Почему живой заход вообще понадобился

Первая редакция плана снимала «до» на посеве. Посев не содержит ни одного заказа, и вывод
команды за март на нём — нули по всем полям. Сравнение нулей с нулями не могло покраснеть ни
при каких обстоятельствах: это было занятое место, а не сторож. Найдено на первом же прогоне
задачи 1; живой заход разрешён владельцем отдельным словом.

## Что живой заход трогал, а что нет

Читались Google Таблица и папка Диска. Писалась **местная** база. Наружу не писалось ничего,
боевая база не открывалась. После снятия файла «до» база возвращена посевом отдельным шагом, и
это подтверждено наблюдением, а не привычкой: вывод команды за март после возврата — снова нули.

Заодно живой заход подтвердил числа загрузки: четыре файла рекламы (1699, 2814, 2908 и 986
байт), 279 строк сырья, 186 после свёртки копии — копия `meta_2026-03 (1).csv` свёрнута с
`meta_2026-03.csv`, 93 строки.

# Сверка чисел на куске S11

| Файл | Что это |
|---|---|
| `метрики-2026-03-до-s11.txt` | вывод команды метрик за март **до** первой правки S11, снятый на живых данных 10 сентября 2026 года командой `npm run --silent metrics -- 2026-03` |
| `метрики-2026-03-после-s11.txt` | вывод той же командой **после** куска S11, на живых данных 11 сентября 2026 года, голова `bab037a`. С файлом «до» совпадает побайтно: `cmp` — код 0, по 2251 байту |

**Сличение с независимым счётом владельца — один раз, по пяти строкам, на файле «до» S11.** Сверка
командой по кодам символов, а не глазами: в строках два вида пробела — неразрывный в разрядах и перед
«×», обычный перед «€» и «%».

| Строка | Счёт владельца | Итог |
|---|---|---|
| оборот | 18 764,00 € | сошлось |
| чистая выручка | 17 277,04 € | сошлось |
| прибыль | 1 738,53 € | сошлось |
| маржа | 10,1 % | сошлось |
| окупаемость рекламы (по обороту) | 4,23 × | сошлось |

Прибор сверки проверен на красное: на копии, где прибыль изменена на цент, он говорит «не сошлось»
ровно у прибыли и возвращает 1.

**Файл «до» S11 и файл «до» S10** совпадают во всех строках, кроме четырёх строк шапки, которые
печатает `npm`: файл S10 снят без `--silent`, файл S11 — с ним. Побайтное сравнение «до / после»
куска S11 делается с файлом S11 и той же командой.

**Что живой заход трогал.** Читались Google Таблица и папка Диска; писалась местная база, цель
названа в каждой из трёх команд явно. Наружу не писалось ничего, боевая база не открывалась. После
снятия файла база возвращена посевом, и это подтверждено наблюдением: за март снова нули.

**Живой заход «после», 11 сентября 2026 года** — те же три команды с явной целью `local`, те же числа
загрузки: Таблица — 519, 19, 11, 2, 5, 62 строк; папка — 1699, 2814, 2908, 986 байт, 279 строк сырья,
186 после свёртки копии. Затем живая проверка марта куска S11 — 2 из 2: якоря водопада, ряда, товаров
и полосы на пути «нет базы», и возврат посевом со своей проверкой. После — наблюдение командой метрик:
за март 0,00 € по всем деньгам, маржа и окупаемость «нет данных». Наружу не писалось ничего.

**Что живой заход показал сверх чисел:** в источниках один месяц — март. Числа загрузки сошлись с
независимым счётом владельца по всем шести листам Таблицы, так что это свойство данных, а не потеря
при загрузке.
