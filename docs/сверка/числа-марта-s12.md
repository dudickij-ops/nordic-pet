# Сверка чисел марта: до куска S12 и после

Кусок S12 меняет **порядок** строк таблицы товаров и не меняет ни одного числа. Побайтного
равенства вывода команды метрик, которым сверялись прежние куски, поэтому больше нет и быть не
может: порядок строк товаров в выводе команды тот же, что на экране, — это одно умолчание на весь
проект, второго нет.

Сверка проведена иначе и строже, чем «числа на глаз»: сравнивается **состав строк** вывода.

## Как снято

Живой заход 14 сентября 2026 года, местная база:

```
NORDIC_PET_DB_TARGET=local npm run ingest:sheets   # код 0
NORDIC_PET_DB_TARGET=local npm run ingest:ads      # код 0
NORDIC_PET_DB_TARGET=local npm run facts           # код 0
NORDIC_PET_DB_TARGET=local npm run metrics -- 2026-03
```

Загрузка сошлась с независимым счётом владельца по листам Таблицы: заказы 519, возвраты 19, цены
11, ставки 2, расходы 5, курс 62; реклама — 279 строк из четырёх файлов.

## Что вышло

| Что сравнивали | Команда | Ответ |
|---|---|---|
| Строк в выводе до и после | `wc -l` | 50 и 50 |
| Набор строк без учёта порядка | `diff <(sort до) <(sort после)` | пусто, код 0 |
| Строк, вставших на другое место | `diff до после` | 4 |

Четыре строки в позиционном диффе — это две переставленные строки товаров, каждая считается
дважды: `NP-012` и `NP-009` поменялись местами с `NP-003`, потому что порядок стал прибыльным.
Все числа — суммы, доли, штуки, себестоимость, прибыль, блок честности и одиннадцать видов
неполноты — совпали до знака.

Файлы: `метрики-2026-03-после-s11.txt` — до куска, `метрики-2026-03-после-s12.txt` — после.
